# 本仓库实际验证记录

验证日期：2026-10-13。环境：Windows，Python 3.12.10，PyTorch 2.13.0+cpu，CPU 2线程。

## 执行命令与结果

```bash
python -m unittest discover -s tests -v
python -m experiments.run_cpu --output results/verified-cpu.json
```

- 测试：8项，全部通过。
- 实验：120组输出与最终状态对照，全部满足各自容差。
- float64最大输出绝对误差：1.5543122344752192×10⁻¹⁵。
- float32最大输出绝对误差：7.152557373046875×10⁻⁷。
- 原始输入配置、种子、逐组误差、环境与代码SHA-256均在[verified-cpu.json](verified-cpu.json)。

8项测试覆盖：先遗忘再纠错的手算例子，同key覆盖，四种递推机制和非整块尾部，状态续接且不修改调用方状态，未来数据不影响前缀，强衰减下不形成累计倒数，输出与末状态的梯度一致性，以及无效输入显式报错。

## 可重算的数值勘误

float32最大有限值的自然对数约88.72。单纯计算 `α^-C` 超过表示范围的首个整数C为：

| α | 首个溢出块长C |
|---|---|
| 0.99 | 8828 |
| 0.90 | 843 |

这仅是表示范围计算，不说明更早没有精度风险。原HTML的阈值与这项算术不一致，见[勘误](../notes/corrections.md)。

按实际配置只估算token相关MLA缓存，层数比为7/27，减少20/27≈74.07%。它是解析估算，不是显存测量。

## 结论边界

数值一致性支持本仓库教学算子在测试配置内实现同一递推，不证明完整KDA模型优于其他模型，也不证明GPU速度。没有重跑MQAR、通用DPLR计时、48B质量表、SFT/RL或论文6.3倍吞吐。原资料图表属于历史报告，和此目录新增结果分开解释。
